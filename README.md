# SpendDNA – Transaction Analyzer

SpendDNA is a Python-based personal finance analyzer that cleans messy real-world UPI transaction data and generates meaningful spending insights.

### What it does:
- Cleans inconsistent date & amount formats
- Extracts vendor names from messy descriptions
- Categorizes transactions
- Detects spending patterns (time-of-day, monthly trends)
- Flags anomalous transactions using z-score
- Assigns spending archetypes

### Tech Stack
- Python
- Pandas
- NumPy

### Dataset
Analyzed 1,310 transactions from Jan 2024 – Jun 2024.

### Key Insights
- Heavy e-commerce spending
- Clear late-night food ordering pattern
- Negative savings rate
- Detected archetypes: **The Shopaholic** + **The YOLO Spender**
